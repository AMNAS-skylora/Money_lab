# Money Lab

A private-on-device, mobile-first money and savings tracker. Plain HTML, CSS and JavaScript; no build dependencies.

## Use
Serve this folder over HTTPS (Vercel: import repository, Framework Preset Other, no build command, output directory "."). For local development use `python3 -m http.server 5173` and open localhost:5173.

In iPhone Safari, use Share → Add to Home Screen → Open as Web App. First load needs a connection; the service worker then caches the app for offline use. Apple touch icons are generated by the CI asset script. Browser storage is device/origin-specific and is not cloud backup. Export JSON backups regularly, especially before clearing Safari data or changing domains.

## Features
- Income and expenses; transfer available money into savings and withdraw it back.
- ₹25/₹30/₹50 quick saves, custom amounts, configurable savings percentage.
- Editable goal and target date, monthly summary, activity search/filter, CSV export.
- Undo deletion with ledger validation; integer paise accounting.
- Validated versioned JSON export/import, no third-party scripts or analytics.
- Installable manifest, offline shell, safe-area layout, keyboard-friendly forms.

Records track money manually; this app does not connect to a bank or transfer real funds. Starting balances are zero: record income before allocating it to savings.

## Checks
`node --test tests/ledger.test.mjs`
`node scripts/icons.mjs` generates PNG app icons with Node built-ins.
CI runs checks and creates a static site artifact for deployment. No credentials required.

## Privacy
Financial records stay in localStorage on the current device. Anyone with access to this browser profile can open them. JSON/CSV exports contain your records; store them privately. This version has no login, bank integration or cross-device sync.
